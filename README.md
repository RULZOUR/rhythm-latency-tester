## *EN*

# Rhythm Latency Tester

A simple and accurate tool for measuring audio latency and calculating the optimal offset for rhythm games (osu!, Quaver, Etterna, etc.).

## Download
You can download the ready-to-use `.exe` file in the **[Releases](../../releases)** section.

## How to Use
1. Launch the application.
2. Click **Start** (or press `Enter`).
3. Listen to the beat and press **Space** (or click the mouse) right in time with the sounds.
4. Make 15–20 taps.
5. Check the **"Recommended Offset"** section.
6. Enter this value (e.g., `-25 ms`) into your game's `Audio Offset` / `Universal Offset` settings.

## Why is this useful?
Even wired headphones on Windows can have a 30–50 ms delay due to audio drivers. This test helps find the exact value so you can compensate for it in-game and hit every note perfectly on beat.

## Localization
Supports Russian and English (language switcher in the top-right corner).

### *RU*

# Rhythm Latency Tester

Простой и точный инструмент для измерения задержки звука (Audio Latency) и расчета оптимального оффсета для ритм-игр (osu!, Quaver, Etterna и др.).

## Скачать приложение
Ты можешь скачать готовый `.exe` файл в разделе **[Releases](../../releases)**.

## Как пользоваться
1. Запусти программу.
2. Нажми **Старт** (или клавишу `Enter`).
3. Слушай ритм и нажимай **Пробел** (или кликай мышкой) ровно в такт звукам.
4. Сделай 15-20 тапов.
5. Посмотри на блок **"Рекомендуемый оффсет"**.
6. Вбей это значение (например, `-25 мс`) в настройки `Audio Offset` / `Universal Offset` в своей игре.

## Почему это полезно?
Даже проводные наушники на Windows могут иметь задержку в 30-50 мс из-за драйверов. Этот тест помогает вычислить точную цифру и компенсировать её в игре, чтобы ты тапал идеально в такт.

## Локализация
Поддерживается русский и английский языки (переключатель в правом верхнем углу).
